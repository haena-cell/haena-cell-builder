# Hurdle 크롬 확장 프로그램 (D-33, D-47, D-48)

보고 있는 채용 공고 화면에서 아이콘을 누르면, 그 화면의 글(이미지 공고면 화면 캡처)을 Hurdle로 보내 정리하고, 아이콘 아래 작은 창에서 확인한 뒤 바로 저장해요.

## 설치 (개발자 모드, 무료)
1. 크롬 주소창에 `chrome://extensions` 를 입력해 열어요.
2. 오른쪽 위 **개발자 모드**를 켜요.
3. **압축해제된 확장 프로그램을 로드합니다**를 눌러요.
4. 압축을 푼 `hurdle-extension` 폴더(저장소에서는 `extension` 폴더)를 골라요.
5. 크롬 오른쪽 위 퍼즐 모양 아이콘 → Hurdle 옆 **고정(핀)** 을 누르면 아이콘이 항상 보여요.

## 쓰는 법
1. 크롬에서 Hurdle(https://hurdle-jobs.vercel.app)에 로그인해 둬요.
2. 채용 공고 화면(사람인·잡코리아·인스타그램 등)을 열고 Hurdle 아이콘을 눌러요.
3. 작은 창에 링크·기업명·직무·마감일이 채워져요. 근무지·제출 서류·전형 절차는 [더보기]에서 확인해요.
4. 노란 칸을 확인하고 [저장]을 누르면 내 Hurdle에 저장돼요.

## 읽는 것과 보내는 곳
- 아이콘을 **누른 탭 하나만** 읽어요(activeTab). 다른 탭·방문 기록은 읽지 않아요.
- 보내는 곳은 Hurdle 주소뿐이에요. Hurdle 서버가 정리할 때 빈 칸은 AI(Anthropic)에 보내요(전화번호·이메일은 지우고).
- 화면 글은 정리에만 쓰고 원문으로 저장하지 않아요. 링크는 저장해요.
- 정리 결과와 고친 내용은 창이 닫혀도 이어지도록 이 크롬에 잠깐 보관하고(크롬을 끄면 사라져요), 저장하면 지워요.
- 비밀번호나 키를 저장하지 않아요. 같은 크롬의 Hurdle 로그인을 그대로 써요.

## 고친 뒤 다시 불러오기
`popup.js` 등을 고쳤거나 새 파일을 받았으면 `chrome://extensions` 에서 Hurdle의 **새로고침(↻)** 을 눌러요.
개발 중 이 컴퓨터(localhost)로 보내려면 `popup.js` 의 `APP` 을 `http://localhost:3000` 으로 바꿔요.

## 배포용 파일 만들기
`extension` 안의 파일을 고쳤으면 `npm run ext:zip` 으로 `public/hurdle-extension.zip` 을 다시 만들어 함께 커밋해요. 메뉴의 [확장 프로그램] 화면이 이 파일을 내려받게 해요.
